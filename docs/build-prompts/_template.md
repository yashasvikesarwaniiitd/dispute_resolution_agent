# Phase N: <name>

Every phase prompt uses these sections, in this order.

## Role
Who you are for this phase, in one sentence.

## Context
What exists already and what to read first.

## Objective
The single outcome of the phase, in one or two sentences.

## Scope
### In scope
### Out of scope
Things that look related but belong to later phases or the backlog.

## Tasks
Numbered. Each task is small and ends with a test or a visible result.

## Technical requirements
Constraints on design, libraries, data and interfaces.

## Acceptance criteria
Observable, verifiable statements. For each, name the command or test that proves it.

## Deliverables
Files, docs, ADRs and demos.

## Constraints
Invariants from CLAUDE.md that this phase touches, and any extra limits.

## Process
Plan mode first. Open questions with defaults. One task at a time.

## Model and effort
Which model plan to use, and when to escalate to Opus.

## Stop and ask if
Conditions that must interrupt work.
