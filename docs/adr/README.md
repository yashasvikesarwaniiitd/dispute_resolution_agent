# Architecture decision records

One file per significant decision: `NNNN-short-title.md`. Keep each under 40 lines. Decision and reason first.

```
# ADR NNNN: <title>

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Decision
One or two sentences.

## Why
The reason, in plain language first, then the technical detail.

## Options considered
The main alternatives and why they lost.

## Consequences
What gets easier, what gets harder, what to watch.

## Sources
Official documentation links actually read.
```
